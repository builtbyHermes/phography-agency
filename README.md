# 📸 Photography Agency & Client Portfolio

A fully custom photography agency and client portfolio website. This project was handled end-to-end—from initial UI/UX wireframing and design systems in Figma to full-stack frontend development, optimization, and final production hosting.

## ✨ Features

- **Immersive Visual Layouts:** High-impact gallery sections, lightbox views, and smooth image loading optimized for visual storytelling.
- **Client Portal / Booking:** Streamlined inquiry and booking flows for prospective clients.
- **Responsive Design:** Fully adaptive layouts providing an exceptional experience across mobile, tablet, and desktop viewports.
- **Performance Optimized:** Fast asset delivery, lazy-loaded imagery, and clean semantic markup.

## 🛠️ Tech Stack & Workflow

- **Design:** [Figma](https://www.figma.com/) (UI/UX design systems, prototyping, and layout architectures)
- **Frontend:** [React](https://react.dev/) / [TypeScript](https://www.typescriptlang.org/) / [Tailwind CSS](https://tailwindcss.com/) _(adjust based on your exact stack)_
- **Hosting & Deployment:** [Vercel / Netlify / GitHub Pages] _(choose your host)_

## 🚀 Project Phases

1. **Discovery & Wireframing:** Defining brand identity, user flows, and low-fidelity layouts.
2. **UI/UX Design:** Crafting high-fidelity components, typography pairing, and dark/light modes in Figma.
3. **Development:** Building modular, reusable components with smooth animations and responsive grids.
4. **Deployment & Hosting:** Setting up custom domains, SSL, and continuous deployment pipelines.
